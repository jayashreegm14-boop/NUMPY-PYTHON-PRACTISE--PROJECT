📊 Student Marks Analysis Using Python NumPy

📌 Project Overview

This project focuses on analyzing student marks using Python NumPy. It performs array operations, statistical calculations, filtering, sorting, and missing value handling to understand student academic performance.

The project demonstrates how NumPy simplifies numerical calculations and data analysis.

🎯 Objectives

Analyze student marks in different subjects.

Find the highest and lowest marks in each subject.

Identify the student with the highest overall average.

Filter students based on Python marks.

Add bonus marks to SQL with a maximum limit of 100.

Handle missing values using subject-wise mean.

Sort students based on average scores.

Calculate the percentage of students scoring an average of at least 60.

📈 Project Features

1. Highest and Lowest Marks

Finds the maximum and minimum marks in each subject using np.max() and np.min().

2. Highest Overall Average

Identifies the student with the highest average using np.mean() and np.argmax().

3. Student Filtering

Finds students who scored at least 75 in Python using Boolean Masking.

4. Bonus Marks Calculation

Adds 5 bonus marks to SQL while restricting the maximum mark to 100 using np.minimum().

5. Missing Value Handling

Replaces missing values with the corresponding subject mean using np.nanmean() and np.isnan().

6. Student Ranking

Sorts students from highest to lowest average using np.argsort().

7. Percentage Calculation

Calculates the percentage of students whose average score is at least 60.
